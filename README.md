# axi-paper-release: data and code behind the two Gemma 4 Developer Agent paper-track writeups

W1 "What Does a Fixed Model Gain from the System Around It?" and W2 "AXI-Fresh: Post-Cutoff Tasks for Measuring Developer Agents" (PDFs here; supplement S1 to S7 for W1).

Files: ledger-public.jsonl (the run, leaderboard, gate and check rows the papers cite by id; run rows carry per-task outcomes; the 34 holdout task ids are redacted; numbers read from agent traces are not in it), e3-verdicts.csv (one row per judged patch of the referee study: task, configuration, the four check verdicts, the hidden-test outcome), e3-session-exit.csv (whether the session that produced each patch timed out), p6-tasks.csv (the 62 AXI-Fresh tasks with the system arm r0045 and the floor arm r0054 outcomes), public-trajectories.csv (verdicts on samples of two public trajectory sets, nebius/SWE-rebench-openhands-trajectories and nebius/SWE-agent-trajectories on Hugging Face, both CC BY 4.0, Nebius; it holds instance ids and verdicts only; supplement S5), public-task-audit.csv (25 public tasks: 24 whose reference fix fails in the sandbox and one that an empty patch also passes), statements.md (the 62 AXI-Fresh problem statements), hard-subset.txt (the 31 larger-fix tasks), events-2026-11-08.json (the process counts of supplement S6, counted on 2026-11-08), preregistration/ (the texts of P5, P6 and P7 with their amendments, and SHA256SUMS.txt, the hash list also published as ghaisank/axi-preregistration-hashes), analysis/ (the analyses the papers cite: e3-terminal-01, the finished-session block of W1 Table 1; e3-combo-01, the combined checks and the self-claim on the executed checks' subsets, W1 Section 4 and Table 1 row 5; e3-public, the public-trajectory pilot of supplement S5 and W1 Section 6; mde, the detectable-lift figures; parser-tax, statement-cues and trace-fail-01), code/ (the exporters that built these files, recompute.py, the public notebook's script, and mde.py).

Edits of 2026-11-10 to this public copy: the free-text notes of ledger rows r0051 to r0054 and the tags of r0052 and r0053 were shortened, and three phrases of P6's amendment A4 are left out and marked in the text (preregistration/README.md). No number, row id, instrument field or per-task outcome changed.

Recompute: `python3 code/recompute.py <this folder>` prints W1 Table 1 (pooled and finished-session blocks) and Table 2 from these files; the notebook ghaisank/axi-paper-recompute runs the same script on Kaggle.

The AXI-Fresh problem statements (statements.md) were drafted by helper agents running under Claude Code, under the author's rules, and read by the author. Because a closed model drafted them, the set is meant for evaluation; training on it would use closed-model output.

The AXI-Fresh tasks themselves are in ghaisank/axi-fresh-v2 (code under each repository's licence, statements CC BY 4.0). Agent configurations are withheld until the main track closes on 2026-12-02.
